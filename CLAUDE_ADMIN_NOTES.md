# Claude Admin Notes

This file is generated by `scripts/sync_claude_admin_notes.mjs` from the
`admin_codex_notes` Supabase table, filtering for notes targeted at Claude.

When a new Claude Code session opens, scan this file before doing anything
else. It surfaces:

1. **Questions for Claude** — answer these first (Tom is waiting on me).
2. **Pending Changes** — proposals to apply (change_request / proposal_add /
   proposal_delete). Each carries the entity's full Swift snapshot so I can
   act without re-exploring.
3. **Open Feedback** — grouped by entity. Read these when working on the
   relevant area.
4. **Recently Applied (last 30 days)** — audit log of changes I've shipped.

Older applied notes are moved to `CLAUDE_ADMIN_NOTES_ARCHIVE.md`.

To regenerate this file:

```sh
CHEZ_ADMIN_PASSWORD=… node scripts/sync_claude_admin_notes.mjs
```

When I apply a proposal, I run:

```sh
node scripts/mark_admin_note_applied.mjs <note_id> [commit_sha]
node scripts/post_admin_note_reply.mjs <note_id> "Applied in commit X. …"
```

Then re-sync to refresh this file.
